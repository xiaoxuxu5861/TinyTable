TinyTable Portable
==================

Run TinyTable.exe directly. No installation is required.

Snapshots, selection sets, and settings are stored in:
  .\data\layout-snapshots.json

Keep TinyTable.local-data beside TinyTable.exe. Removing that marker changes
the data location back to %LOCALAPPDATA%\TinyTable.

On the first run, TinyTable.portable selects the closest supported Windows
display language. Later language choices are saved and are not overwritten.

To move the portable copy, close TinyTable and move the entire folder.
